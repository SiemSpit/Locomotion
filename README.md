# Locomotion

Project: Simulating locomotion in active elastic systems 

Understanding how biological systems adapt to complex 3D environments is key to designing resilient and versatile robots. Organisms like starfish, jellyfish, and flagella move without a central brain, relying on soft-body deformations to navigate their surroundings. Their ability to integrate multiple deformation modes enables efficient, adaptive motion. This project explores how to replicate such behaviors by simulating active tensegrity structures with non-reciprocal actuators. These flexible, responsive systems generate movement through controlled actuation, mimicking nature’s responses.  

 
The project combines fundamental mechanics, material testing, computational modeling, and data visualization. Students will measure elastic properties using a fatigue testing machine, implement Python-based simulations, and develop active tensegrity models to study motion dynamics. Through data analysis and visualization, they will interpret experimental and computational results effectively. 

For those interested in further research, the project can be extended to investigate nonlinear wave propagation in active tensegrity structures, uncovering new insights into bio-inspired locomotion.
